Smart energy grid failure management

An automated grid that keeps power flowing to what matters when something fails.

{{ icon('bolt') }}

Motivation

Energy grids supply homes, businesses and industry, and they fail in ways that are slow to find and slower to fix.

  • Restore power quickly after a disturbance.
  • Cut the cost of operating and managing the grid.
  • Keep critical infrastructure supplied while a fault is cleared.
  • Improve security and visibility across the whole circuit.
{{ icon('shield') }}

How it works

  • Appliances are assigned priorities, so load is shed from the bottom up.
  • Devices can be added, removed and reordered without touching the firmware.
  • Power is redirected around a failure rather than dropped.
  • Current and temperature sensors catch overheating, overloading and power theft.
  • This web app shows grid status and switches appliances remotely.
{{ icon('circuit') }}

What the rig is built from

Hardware

  • Relays switch current to each appliance.
  • Potentiometers set the voltage difference between grid preferences.
  • ACS712 current sensors measure draw on every branch.
  • DC motors, LEDs and buzzers stand in for household appliances.

Software

  • OM2M provides the oneM2M middleware the ESP boards subscribe to.
  • ThingSpeak collects readings and serves them back as JSON.
  • This Flask app reads both, and writes control commands to either.
  • Charts render locally from the same data the tables show.

Failure modes it catches

  • An appliance drawing power while switched off, which reads as theft.
  • Draw drifting away from the appliance's rated current.
  • Overheating on the motor branches.
  • A gateway or channel going quiet.
